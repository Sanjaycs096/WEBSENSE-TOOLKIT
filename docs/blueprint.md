# **App Name**: WebSense Toolkit

## Core Features:

- Network & IP Analysis: Detect and display IPv4/IPv6 addresses, public IP, geolocation data (country, ISP, ASN), and VPN/Proxy detection. Includes DNS resolver information.
- Internet Speed Test: Measure download speed, upload speed, ping, and jitter using browser-based WebRTC methods. Display results visually.
- URL & Website Analyzer: Perform URL safety checks, SSL certificate validity checks, HTTP security header analysis, and website uptime pings. Generate a performance score.
- Password Toolkit: Offer a client-side password strength checker (entropy based) with a visual strength meter. Also, provide a strong password generator and a password leak check using hash-based k-anonymity.
- AI Image Authenticity Checker: Allow users to upload an image and detect if it is AI-generated versus real. Show a confidence percentage and explain the results. Includes metadata inspection using AI as a tool.
- Unified Digital Safety Score: Generate a WebSense Safety Score (0–100) based on IP exposure risk, URL safety results, password strength, browser security headers, and AI content trust. Store score history for logged-in users and display graph trends.
- User Scan History: Store user scan history including IP scans, URL scans, speed tests and AI checks. Display score history trend to users.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to evoke trust and security, suitable for a cybersecurity context.
- Background color: Light, desaturated blue (#E1F5FE), providing a clean and non-intrusive backdrop for the content.
- Accent color: Analogous cyan (#4BC9E4), brighter than the primary, to highlight interactive elements and important information.
- Secondary color: A calm green (#4CAF50) to indicate safety and reliability, complementing the blue tones.
- Body font: 'PT Sans' (sans-serif) for a modern, approachable, and readable text.
- Headline font: 'Space Grotesk' (sans-serif) to bring a techy look to the titles. For longer text blocks, use 'Inter'.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use clean, minimalist icons to represent different tools and results. Ensure icons are easily recognizable and consistent throughout the application.
- Implement a card-based dashboard layout for easy navigation and content organization. Cards should be clearly labeled and visually appealing.
- Incorporate subtle animations for loading indicators, transitions, and displaying results. Animations should be smooth and not distracting.
- Dark Theme: Use a dark gray (#333333) background with light gray (#DDDDDD) text for comfortable night viewing.
- Light Theme: Use a white (#FFFFFF) background with dark gray (#333333) text for optimal daytime viewing.
